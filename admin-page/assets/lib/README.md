ExcelJS 4.4.0 browser bundle (`dist/exceljs.min.js`) from the official `exceljs@4.4.0`
npm package. License: MIT, reproduced in `exceljs-LICENSE.txt`.

Used by the shared Reports / Inventory workbook exporter. Vendored so exports do
not depend on a third-party CDN being available. No npm install is needed on the
production server; deploy these files with `admin-page/report-excel.js`.
