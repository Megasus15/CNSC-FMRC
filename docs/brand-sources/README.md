# Brand logo sources

- `UCN original photo.jpg` is the supplied UCN source image. Its large empty margins make the mark too small in the site's compact logo holders.
- `images/UCN Logo.png` is the approved, centered 512 × 512 UCN mark used as the site default. It keeps the same red glyph on a clean white background.
- `images/FMRC Brand Logo.png` is a byte-for-byte copy of the supplied FMRC PNG and is used for the site's FMRC brand defaults. The older `images/FMRC Logo.png` remains for unrelated product image placeholders.
