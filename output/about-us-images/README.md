# About Us image collection

Twelve maroon-and-cream flat illustrations generated with the built-in image_gen tool, using the supplied Services and maintenance artwork as style references.

## Upload order

- Upload `vision-main.png` to the **Vision Image** field.
- Upload `vision-gallery-01.png` through `vision-gallery-05.png`, in that order, to **Vision Photo Gallery**.
- Upload `mission-main.png` to the **Mission Image** field.
- Upload `mission-gallery-01.png` through `mission-gallery-05.png`, in that order, to **Mission Photo Gallery**.

The images are composed for the existing 16:10 fit window. Keep the centered composition when applying the crop. The existing page shows the gallery when gallery images are present; the main image serves as its fallback.
